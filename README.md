# SMA Sunny Portal Data Downloader (ennexOS)

This project enables downloading all data visualized in the [SMA Sunny Portal (ennexOS)](https://ennexos.sunnyportal.com).

## Installation

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd SMA-Sunny-Portal-Data-Downloader-ennexOS-
```

## Execution

To start the application, run the following command from the project's root directory:

```bash
python3 -m downloader.main
```
